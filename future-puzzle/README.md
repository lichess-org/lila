# Future Puzzle Resources

This directory is not part of the active website runtime.

It contains preserved Lila puzzle source code, import/maintenance scripts, old compiled puzzle assets, configuration templates and translations. Keep it only until the new puzzle backend and Lichess import pipeline are ready.

## Folders

- `source/puzzle-module/` - legacy puzzle domain source.
- `tools/mongodb-scripts/` - migration and repair scripts.
- `tools/cron-jobs/` - denormalization jobs.
- `assets/` - old compiled puzzle assets.
- `config/` - old configuration templates.
- `locales/` - puzzle translations.

The active site is in `../school-portal/`.
